# Publicação e medição

O domínio canônico deste projeto é https://mulhernaosecale.com.br/. Se outro domínio for usado, atualize canônicos, Open Graph, JSON-LD, robots.txt e sitemap.xml juntos.

Publique a pasta inteira, incluindo robots.txt, sitemap.xml e images/social-share.jpg. O HTML único é uma prévia; o ZIP contém os arquivos para o domínio público.

Após publicar, valide as páginas no Rich Results Test e no Schema Markup Validator, confira HTTP 200 das duas páginas e dos assets e envie sitemap.xml no Google Search Console. Verifique a propriedade com a conta do responsável; não há credenciais incluídas. Configure um redirecionamento 301 de /index.html para / e escolha um único host HTTPS no provedor.

O arquivo robots.txt não impede acesso privado; /admin.html não está incluído neste projeto. A autorização do painel, se houver, deve ser configurada no servidor.

FAQ e dados estruturados descrevem conteúdo visível. Não há promessa de rich results, indexação, ranking ou citação por IA. Não foram inventadas avaliações, resultados ou próximas edições. Estatísticas herdadas do site precisam de fontes e períodos de medição documentados pelo responsável antes de divulgação como indicadores oficiais.

Acompanhe indexação, buscas por marca e por tema, cliques, CTR e Core Web Vitals no Search Console. Valide a integração externa da Maria separadamente: no teste anterior ela não retornou uma resposta válida.

Referências: https://developers.google.com/search/docs/appearance/ai-features e https://www.gov.br/mulheres/pt-br/ligue180
